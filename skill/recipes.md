# 按题材翻的做法

主文档 SKILL 只写每张画都用得着的东西。下面这些是画到某种题材时摔过的，画到了再翻，用不上就别管。

**树冠、叶丛。** 先铺一层底当作空气，再用 HARD 的小块拼出一簇簇叶子。叶丛要一层压一层往后退：先铺浅的，再在它周围画深一档，把第一层剩出来。远处的叶子用干笔（`water` 0.2–0.3）擦，挂在纸纹上出碎白。（小巷）

**草和毛。** 用扇笔或干笔，顺着长的方向扫。不想让它落到块外面，就用 `stroke(..., within=块)`。

**细枝、桅杆、电线、草茎、藤。** rigger 配 `trail()`，出锋收笔。越长越细用 `pressure=lambda t: 0.95 - 0.8 * t`。石板缝、短草茎用 `wobble=0.25`，画几道长的，别画满地小逗号。（小巷）

**树皮的纹、裂缝、窗框。** 把形画成撕开的楔形（`lasso` 配小 `scale` 的 `jag`），`fill(..., edge=HARD)` 盖上去。（白桦林）

**窗、洞。** 一块暗，上沿深一截，窗台亮一点，不要画成框线。窗是开在墙上的洞，大小、亮度、暖度都不一样。（上面还是白天）

**积云。** 先画整座云左亮右暗的大形，每一团的明暗只是挂在上面的小起伏。每团都把明暗给足，就是满头紫斑。别给每一团各算一个月牙影，那样是长颈鹿纹；影是一整块，左边被迎光的那几团咬出一串弧。（上面还是白天）

**虞美人这类杯状的花。** 黑斑是花瓣自己的颜色，长在每片花瓣根部，形状跟着花瓣，边清楚，斑和斑之间露出红。杯子里面另有一层跟着光走的影：往迎光那边慢慢淡下去，贴着前面那片卷边的地方最锐。花心的果别提得太亮太圆，会变成一颗珍珠。（虞美人）

**俯视的水边。** 浪头是一串朝岸鼓出去的圆弧，长短不一，尖朝海。只有前沿那一下最亮最脆，后面的泡沫是泡挤成的一条带子，尺寸跟着画里的东西走（石头巴掌大，带子就拇指宽），不是一个个泡的尺寸。带子和网都不是一根根线画的，是一整片浅色上挖洞：靠岸那边实的不挖，往海里洞越挖越大，最后散成网，三条交汇的地方自然鼓一点。水面的光（泡沫、反光的线）边干净、两头收尖；透过水看见的沙底是糙的，深浅台阶照样喷开。全画最亮最脆的白留给主角，水线压一档。摔过的：横的波纹（平视才有）；从水边按距离推出来的平行线（成了等高线、成了绳子）；外面那道浪也从岸线往外推，岸线的凹角推出去就折成了尖，浪头突出去也该是圆的——外浪直接手画一条顺的弧；拖尾的细丝垂直于浪（成了一圈毛、像草，参考里它们顺着浪拉）；照着教程把"网"读成字面、换成满屏小洞（成了海绵）。参考：Patricia Tokarz 那张深蓝水彩的浪头，和一张平涂的俯视海滩。这一条只管从正上方往下看；平视、斜看的浪是另一回事，浪尖翻起来可以是尖的，倒影和横波见 SKILL 第四节"水"。（许愿石）
